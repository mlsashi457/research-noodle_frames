Interaction Manual

This dashboard provides a purely **geometric interpretation of probability**. The bounding box represents the entire Sample Space \(S\), and the circles represent subsets:

  • **Drag-and-Drop:** Move either circle around the space to observe changes in overlap.
  • **Resize Sliders:** Grow or shrink the circles. Notice how increasing the radius increases the event probability.
  • **Boundary Constraints:** Circles are restricted from leaving the box \(S\), making their probabilities exactly equal to the circle area divided by the box area.

Mutually Exclusive Logic

When Mutually Exclusive Events is toggled on, it represents a physical scenario where events \(A\) and \(B\) cannot occur together (\(A \cap B = \emptyset\)).

The simulator forces \(P(A \cap B) = 0\) by using a relaxation constraint solver. If you drag the circles close to one another, they will push each other away. If a circle hits the outer boundary of the Sample Space \(S\), the pushed circle will react and push the dragged circle back, preventing any penetration.
